# eBPFGnarator
shell script can create eBPF project structure

## What is eBPF ?
- eBPF (extended Berkeley Packet Filter) is a revolutionary Linux kernel technology that lets you run custom, sandboxed programs directly inside the operating system kernel. It enables developers to add high-performance networking, deep system observability, and real-time security capabilities at runtime without changing kernel source code or loading traditional kernel modules.


## How to use ?
```bash

$ git clone https://github.com/ziy0s/eBPFGnarator

$ cd eBPFGnarator

$ chmod +x generator.sh

$ ./generator.sh

```
